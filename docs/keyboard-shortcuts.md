# Keyboard shortcuts

Shortcuts work while no text field has focus. The same list is in the app under **Settings → Keyboard shortcuts**.

## Modes

| Key | Action                       |
| --- | ---------------------------- |
| 1   | Create image                 |
| 2   | Edit image                   |
| 3   | Inpaint area                 |
| 4   | Extend image (outpaint)      |
| 5   | Extras (generation data, upscale) |

## File and history

| Key                     | Action       |
| ----------------------- | ------------ |
| Ctrl+Enter              | Generate     |
| Ctrl+O                  | Open image   |
| Ctrl+S or Shift+S       | Export       |
| Shift+N                 | New image    |
| Ctrl+Z                  | Undo         |
| Ctrl+Y or Ctrl+Shift+Z  | Redo         |

## Prompt

| Key                  | Action                                                                                  |
| -------------------- | --------------------------------------------------------------------------------------- |
| Ctrl+Up / Ctrl+Down  | Raise or lower the weight of the selection or the word at the cursor by 0.1 (Shift: 0.05) |
| `<` in the prompt    | Open the image reference picker (arrows to choose, Enter to insert, Escape to close)     |

## Canvas

| Key                       | Action                                                      |
| ------------------------- | ----------------------------------------------------------- |
| G or Space                | Hand tool (Space plus drag pans temporarily)                |
| C                         | Move and resize the generation frame (Edit and Inpaint)     |
| B                         | Brush (drawing layer)                                       |
| M                         | Mask brush                                                  |
| E                         | Eraser                                                      |
| , and .                   | Smaller and larger brush                                    |
| H                         | Show or hide the mask                                       |
| Shift+M                   | Clear the mask                                              |
| S                         | Set as starting image                                       |
| A                         | Show or hide image adjustments                              |
| V                         | Show or hide the adjustment preview (while adjusting)       |
| + and -                   | Zoom in and out                                             |
| 0                         | Zoom to 100 %                                               |
| F                         | Fit view                                                    |
| Mouse wheel               | Zoom around the pointer                                     |
| Ctrl + mouse wheel        | Brush size                                                  |
| Middle mouse button drag  | Pan                                                         |

## Variants

| Key                    | Action                              |
| ---------------------- | ----------------------------------- |
| Left / Right arrow     | Previous or next variant            |
| V                      | Compare before and after            |
| Enter                  | Apply variant as working image      |
| Delete                 | Remove variant                      |
| Shift+D                | Delete all variants                 |
| Shift+V                | Show or hide the variant strip      |
| Escape                 | Clear selection                     |

## View

| Key     | Action          |
| ------- | --------------- |
| Shift+C | Backend console |
